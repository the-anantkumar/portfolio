# portfolio

This repository contains a minimal Tailwind CSS setup.

## Setup

1. Install dependencies:
   ```bash
   npm install tailwindcss postcss autoprefixer
   ```
2. Generate configuration files:
   ```bash
   npx tailwindcss init -p
   ```
3. Build the CSS:
   ```bash
   npm run build
   ```

Open `index.html` in a browser to verify the `Tailwind is working!` message appears styled.
