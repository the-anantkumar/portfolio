# Grounded answer generation experiment

This local experiment tests whether a small instruction model can write concise answers from complete public portfolio passages. It isolates generation by supplying relevant evidence directly; it does not measure retrieval quality. No visitor-facing feature or model API is enabled.

Candidate: `HuggingFaceTB/SmolLM2-135M-Instruct`, revision `12fd25f77366fa6b3b4b768ec3050bf629380bac`, q8, Apache-2.0. The weight file is 137,147,981 bytes, before tokenizer and runtime assets. The [model card](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct) explicitly notes possible factual and logical errors. [Pinned files](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct/tree/12fd25f77366fa6b3b4b768ec3050bf629380bac)

## Screening contract

- Use only the public corpus generated by Astro. Never load resumes, private files, customer data, or credentials.
- Pin the model and all model metadata requests. Public file downloads require no inference account or paid service.
- Supply at most three complete passages, preserving scope and role attribution. Reject oversized prompts rather than silently truncating qualifications.
- Generate at most 128 new tokens, greedily. Questions and model output stay local.
- Check citation syntax, allowed source markers, required scope phrases, concise output, and abstention. These checks do not establish semantic support.
- Review every generated claim manually. A well-formed citation can still point to a source that does not support the sentence.

## Promotion gate

This is a screening set, not held-out validation. Before a visitor feature can be proposed, every scoped and unsupported example must pass both automated checks and human source review. A browser run must then preserve the same behavior and meet a measured device budget. Initial experimental download target: under 200 MB including model, tokenizer, and runtime; first-answer target: under 10 seconds on the measured desktop, followed by physical-phone measurement. Desktop results cannot establish phone suitability.

If quality fails, retain the fast navigator and record the failure. Do not lower the source-quality gate, automatically try a paid API, or silently substitute another model.

Raw responses and caches belong under ignored `artifacts/generation/`. Only reviewed, non-PII measurements and findings belong in the committed learning record. A successful model download or fluent paragraph is not acceptance evidence.
